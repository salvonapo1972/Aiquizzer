# Aiquizzer

**Quiz con un agente di intelligenza artificiale.**

Aiquizzer è un progetto dedicato alla creazione e allo svolgimento di quiz con il supporto di un agente AI. L'obiettivo è offrire un'esperienza interattiva in cui l'intelligenza artificiale possa affiancare l'utente durante il quiz.

> **Stato del progetto:** repository in fase iniziale. Al momento non sono ancora documentati componenti, funzionalità operative o istruzioni di installazione.

## Funzionalità previste

- Esperienza di quiz assistita da un agente AI.
- Interazione con l'utente durante lo svolgimento delle domande.

Queste descrizioni indicano l'obiettivo del progetto e non garantiscono che le funzionalità siano già implementate.
